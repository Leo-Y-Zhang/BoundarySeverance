# Data licence

All geographic data used by this project is retrieved from OpenStreetMap via
the Overpass API.

OpenStreetMap data is (c) OpenStreetMap contributors and is made available
under the Open Database Licence (ODbL). See https://www.openstreetmap.org/copyright

This applies to the cached Overpass responses, the derived road graphs, the
boundary geometries, and any figure drawn from them. The MIT licence in
`LICENSE` covers the source code only.
